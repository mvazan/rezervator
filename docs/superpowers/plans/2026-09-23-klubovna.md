# Klubovna (PR B: results + venues UI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third home tab **Klubovna** — a card hub like Správa kuželny — with two cards: **Výsledky** (the season's matches with live scores, video and a match detail with players and lanes) and **Kuželny** (the alleys our teams play at, with call / e-mail / navigate actions and technical info); plus score + video in the calendar's day-matches dialog.

**Architecture:** Pure Flutter/Riverpod on top of PR A's tables (`match_results`, `match_player_results`, `venues`, new `priority_slots` columns) and RPC `refresh_match`. Pure domain helpers in `lib/domain/results.dart` (tested), streams in `lib/data/providers.dart`, screens in `lib/features/clubhouse/`. A shared `HubMenu` widget renders both Správa and Klubovna, so the list/grid layout exists once.

**Tech Stack:** Flutter 3, flutter_riverpod 3, supabase_flutter (Realtime streams via `cachedRows`), url_launcher (`launchPhone`, `launchEmail`, `launchWeb` in `lib/core/ui.dart`).

**Spec:** `docs/superpowers/specs/2026-09-23-federation-results-design.md` — sections "Appka — PR B" and "Kuželny". Branch `federation-results-ui` is stacked on `federation-sync` (PR A).

```dart
// models.dart
enum HomeView { trainings, calendar, clubhouse }   // clubhouse LAST — IndexedStack order follows declaration
// PrioritySlot gains (all optional, from JSON keys in parentheses):

final String? competition;   // competition
final int? round;            // round
final String? siteSlug;      // site_slug
final int? siteMatchId;      // site_match_id

enum MatchStatus { scheduled, preparation, inProgress, finished, forfeit }  // from 'scheduled'|'preparation'|'in_progress'|'finished'|'forfeit'
class MatchResult { matchId, status, matchType, discipline, homePoints (num?), awayPoints, homeTotal (int?), awayTotal, homeFulls, awayFulls, homeSpares, awaySpares, homeErrors, awayErrors, homeSetPoints (num?), awaySetPoints, fetchedAt (DateTime); factory fromJson; }
class PlayerLane { lane (int), fulls, spares, errors, total (int?), setPoints (num?); } // from lanes jsonb items {lane, fulls, spares, errors, total, setPoints}
class MatchPlayerResult { id, matchId, side ('home'|'away'), position (int), playerName, playerSlug (String?), fulls, spares, errors, total (int?), setPoints, teamPoints (num?), lanes (List<PlayerLane>); fromJson }
class VenueSection { title; List<({String label, String value})> items; }
class Venue { id, slug, name, address?, phone?, email?, lat (double?), lng (double?), sections (List<VenueSection>), clubs (List<String>), fetchedAt; fromJson;
  String? get mapsUrl; }  // lat/lng → 'https://www.google.com/maps/search/?api=1&query=<lat>,<lng>'; else address → same URL with the URL-encoded address; else null

// results.dart
bool isLive(PrioritySlot slot, MatchResult? result, DateTime now);
String pointsLabel(num? home, num? away);   // '5 : 3', '2,5 : 5,5', '–'
String pinsLabel(int? home, int? away);     // '3460 : 3349', or '' when both null
String formatLabel(String matchType, String discipline); // 'TEAMS_OF_6'+'T120' → '6 hráčů · 120 HS'; TEAMS_OF_4 → '4 hráči'; unknown parts omitted
String numLabel(num? v);                    // 2 → '2', 2.5 → '2,5', null → '–'
enum ResultsFilter { mine, all }            // plus a team name filter, see resultsTimeline
List<({Day day, List<PrioritySlot> matches})> resultsTimeline({
  required List<PrioritySlot> slots,        // prioritySlotsProvider
  String? team,                             // a single team (exact name) — wins over mine/all
  required bool mineOnly,
  required List<String> followedTeams,
  required Map<String, bool> exceptions,    // myMatchExceptionsProvider
});  // only type.isMatch && parentId == null && fromFederation; mineOnly uses matchIsMine(); team keeps home==team||away==team; days ascending, matches by startsAt then title
int todayIndex(List<({Day day, List<PrioritySlot> matches})> days, Day today); // first day >= today, else last index, -1 when empty
List<Venue> venuesMatching(List<Venue> venues, String query); // compareCzech by name; query matches name/address/clubs, case- and accent-insensitive (reuse the app's existing accent-folding helper if there is one — grep `fold`/`normalize` in lib/domain/collation.dart)

// providers.dart
final matchResultsProvider = StreamProvider<Map<String, MatchResult>>(...);          // all match_results rows of the tenant keyed by matchId; cache key cacheKeyMatchResults = 'match_results'
final matchPlayerResultsProvider = StreamProvider.family<List<MatchPlayerResult>, String>(...); // eq('match_id', id), sorted side home first then position; cache name 'match_player_results:$id'
final venuesProvider = StreamProvider<List<Venue>>(...);                              // cacheKeyVenues = 'venues', sorted compareCzech
Api.refreshMatch(String matchId) → Future<String>  // rpc('refresh_match', params: {'p_match_id': matchId}) returns 'queued'|'fresh'|'not_live'
// resetTenantScopedProviders invalidates matchResultsProvider and venuesProvider (the family auto-disposes; make it autoDispose).
```
